### Agenda

### <strong>1. Bitcoin Transactions: Core Concepts</strong>
- [Mastering Bitcoin: Chapter 6 - Transactions](https://github.com/bitcoinbook/bitcoinbook/blob/develop/ch06_transactions.adoc)
- [Bitcoin Developer Documentation: Transactions](https://developer.bitcoin.org/reference/transactions.html)
- **What is a Bitcoin Transaction?**: Understanding how transactions move value across the network.
- **The UTXO Model**: How inputs, outputs, and unspent transaction outputs (UTXOs) work.

### <strong>2. Setting Up Polar</strong>
- [Polar Website](https://lightningpolar.com/) — One-click Bitcoin & Lightning development networks.
- [Polar GitHub Repository](https://github.com/jamaljsr/polar)
- **Download & Setup**: Installing and configuring Polar for local development.
- **Creating a New Network**: Spinning up a local Bitcoin regtest network.

### <strong>3. Hands-On Demonstration with Polar</strong>
- **Mining New Bitcoin via Polar**: Mining regtest blocks directly within Polar to generate initial coins.
- **Creating a Wallet**: Setting up a new wallet on a node to receive funds.
- **Viewing Unspent Transactions (UTXOs)**: Checking wallet balances and viewing unspent transactions (`listunspent`).
- **Sending a Simple Transaction**: Observing how a transaction spends an existing UTXO and creates new outputs.
